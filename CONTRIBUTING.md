## 🛠️ Contribution Workflow

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/shreya661/IntervIO.git
   cd IntervIO
   ```

2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Install Dependencies**:
   - **Backend**: `python -m pip install -r requirements.txt`
   - **Frontend**: `cd frontend && npm install`

4. **Verify Tests Pass**:
   ```bash
   pytest
   ```

5. **Commit Your Changes**:
   ```bash
   git add .
   git commit -m "feat: your concise descriptive feature message"
   ```

6. **Push and Open a Pull Request**:
   ```bash
   git push origin feature/your-feature-name
   ```
   Open a PR against the `main` branch on GitHub. Ensure all automated tests pass before merging!
